# 账号同步 0.1.9

2026-10-17。客户端主动连接用户指定的 HTTPS WebDAV；没有项目方中转服务器。Windows、Android、iOS 与鸿蒙共用纯 Dart 协议，本机落盘继续使用各平台原生安全存储。浏览器演示不接收凭据。

## 使用

1. 在 WebDAV 服务建立专用文件夹，填写最终 HTTPS 地址、用户名、应用密码。不会自动创建或遍历父目录。
2. 设置独立同步密码（至少 12 字符）。WebDAV 密码可主动保存于本机加密存档；同步密码仅在页面会话中使用，不保存、不进入任何 HTTP 请求。
3. 第一台设备手动上传，首次再次输入同步密码。第二台使用同一目录与密码下载，预览后合并。
4. 返回游戏页刷新官方状态。同步不重新申请社区 Token，不调用登录、签到、短信或验证码接口；不会用模拟满体力代替查询失败。

云端文件名 `qiyou-vault-v1.json`。上传会替换完整云端备份，必须先解密并预览已有备份。云端有独有账号时应先下载合并再上传。下载合并保留本机独有账号和清单；同一账号默认保留本机会话，可主动选择云端会话。同一清单保留本机进度，两端不同日期的完成状态按北京时间重置；应用云端亮暗和 UID 设置。移除本机账号不自动删除云端副本；再次上传后才更新备份内容。

## 格式与数据流

加密前内容：schema=1、随机 128 位修订号、UTC 创建时间、账号与绑定角色、会话关联设备参数、亮暗设置、隐藏 UID 设置、手动清单及其日期。会话的实际关联参数随会话保留，不生成伪造硬件参数；服务端要求本机验证时重新授权。无体力缓存、签到状态、操作日志、验证码、浏览器配置目录、WebDAV 密码或同步密码。

0.1.10 的账号新增可选 `hiddenGames`：下载合并应用云端游戏移除状态，默认仍保留本机登录会话。旧备份缺失该字段时视为没有移除游戏；旧客户端不识别移除状态，多端应升级后同步。

加密使用现有 PointyCastle 4.0.0：scrypt N=32768,r=8,p=1，256 位派生密钥；每次使用安全随机生成的 16 字节盐和 12 字节 nonce，AES-256-GCM，128 位认证标签。密文与标签连续存入 ciphertext 的 Base64 字段。AAD 的 UTF-8 原文固定为 `app.qiyou/sync/v1;scrypt=32768,8,1;AES-256-GCM`。公开 envelope 字段为 format、version、kdf、n、r、p、cipher、salt、nonce、ciphertext；算法和成本固定，不接受降级或远程指定昂贵参数。参照 [RFC 7914](https://www.rfc-editor.org/rfc/rfc7914.html)，加解密在后台 isolate 执行。

明文最多 480000 字节；网络响应最多 700000 字节；解密后校验 schema、账号/清单数量、枚举、重复键、角色所属社区及会话字段。错密码、认证失败或格式不兼容均不修改本机数据。敏感值不进入异常消息或诊断。普通 Dart 内存无法保证所有字符串副本均被物理擦除，页面离开时释放密码控制器，派生字节缓冲区在使用后清零。

WebDAV 使用 HTTPS、系统证书校验、Basic 应用认证和固定相对文件名；所有请求禁止跳转。PROPFIND Depth=0 用于目录响应检查，实际读写权限以 GET/PUT 为准。首次 PUT 使用 `If-None-Match: *`；已有文件 GET 必须返回强 ETag，覆盖时使用 `If-Match`。412 停止且不重试；没有强 ETag 时允许下载，禁止覆盖已有文件。PUT 后 GET、解密并比对修订号确认；网络中断、响应未确认时引导重新读取。使用 [RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html) 的条件请求，依赖服务器正确履行 HTTP 条件写入语义。

导入预览记录本机内容指纹；确认时若已变化则停止。合并先提交系统安全存储，再修改界面；保存失败保留原账号。WebDAV 配置保留本机，不从其他设备同步，也不随导入被覆盖。

## 边界

- 端到端加密保护云端文件内容；服务仍可见访问 IP、文件大小、时间及自身 WebDAV 账号。密码强度影响离线猜测成本。
- 服务端可以删除或回放旧的合法密文；首版显示备份日期并要求预览，不提供跨设备防回滚保证。
- 不绕过社区单会话、设备绑定、令牌过期和人工验证。库街区等多端共享会话可用性须实际双设备验收。
- 首版手动同步，不含后台任务、自动冲突合并、同步密码更换或在线主设备代理。已有备份密码错误时不会创建新备份覆盖它。
- 本机账号昨天消失的问题按用户要求另行观察，本次不宣称已定位或修复。
