# 华为应用市场上架评估

核对日期：2026-10-15。本文是对当前实现的产品与审核准备评估，不代表华为预审结论。

**结论：产品方向可以继续做；当前原型尚不适合直接公开上架。用户自填服务器是一种部署方式，不能代替接口或素材授权。**

## 依据与待确认事项

华为[《应用审核指南》](https://developer.huawei.com/consumer/cn/doc/app/50104)页面更新于 2026-10-09。与本项目直接有关的条目为：功能完整性 3.4–3.5、第三方登录 3.16、禁止规避审核 4.1、用户隐私第 7 章、知识产权第 9 章，以及不收录类型第 13 章第 26 项。

本项目未修改游戏内存、战斗或资源数值，也未实现自动刷量、验证码破解。不能仅因“游戏工具”四个字就断言它属于外挂，也不能因此承诺一定通过审核。需要把具体读取及签到过程提交华为确认。

| 当前实现 | 本项目判断 | 具体处理 |
| --- | --- | --- |
| 用 Cookie 调用米游社客户端接口 | 风险较高：尚无第三方使用许可证明；能请求成功不等于获得授权 | 正式发行前向米哈游确认允许的认证、数据读取和签到方式；有授权时优先采用授权令牌 |
| 官方网页登录后读取会话 | 官方页面处理密码，但栖游仍会接触登录凭证，并非官方 OAuth 授权 | 如实披露凭证范围和保存方式；取得明确同意；不能包装成“官方授权登录” |
| 原神等官方图标 | 已记录来源，但尚无应用再分发许可证明 | 取得使用许可，或在商店版使用原创识别图形；注明来源不能替代授权 |
| 本地清单和体力计时 | 不依赖米游社账号，可独立提供价值 | 完善手动体力输入、恢复规则、提醒和导入导出，形成真正可用的基础功能 |
| 仅绑定游戏资源账号，无栖游账号 | 是否适用 3.16 尚待确认 | 向华为明确说明用途；如被要求提供华为账号方案，再设计有实际用途的接入 |
| 测试数据与功能占位 | 目前适合开发测试 | 商店版清除测试信息，补齐正式空状态和功能说明；不得以演示替代真实功能 |

## 关于手动填写服务器

可实现一个明确公开的“自托管服务连接”功能：用户填写 HTTPS 地址和独立服务令牌，客户端通过固定 JSON 协议读取数据、请求签到。应用不下载执行 Python、JavaScript 或其他插件代码。服务器功能、数据流和测试环境均向审核人员完整提供。

这能将设备、服务令牌和服务端适配器分开管理，但若服务端依旧未经许可使用第三方接口，问题仍然存在。如果把米游社 Cookie 交给服务端，服务运营者还会新增凭证保管和个人信息处理责任。不能用一个自填地址输入框，把这些责任转给用户。

0.1.9 新增的是用户自选 WebDAV 的端到端加密备份，不是代执行游戏请求的服务器；社区请求继续由本机直接发出。正式隐私政策和审核说明仍需披露可选备份、用户选定的服务、元数据与保存删除方式，见[同步说明](sync.md)。这一功能不能代替游戏接口及素材授权，也不代表已经满足上架要求。

## 建议的发行边界

1. 先用 Windows / Android 开发版验证本人账号的登录、数据读取、签到及退出后的清理。失败必须显示真实状态，不能用示例值代替。
2. 商店版以本地管理和计时为基础，仅在第三方许可及审核边界明确后提供相应联网能力。尚未解决的功能从商店构建中实际移除，不预留暗门、远程开关或审核后恢复入口。
3. 完成运营者信息、正式隐私政策、同意与撤回、数据清理、SDK披露，并按[应用资质要求](https://developer.huawei.com/consumer/cn/doc/80301)核实备案和提交材料。
4. 就“资源账号绑定是否适用 3.16”“本人账号点击签到是否可收录”“需要哪些接口及图标授权材料”提交[华为开发者工单](https://developer.huawei.com/consumer/cn/support/feedback/)。本次没有代发工单。

现有测试版加入了连接前告知和主动同意，但这不等于完成正式上架所需的全部隐私工作。开源、免费、写免责声明均不能自动消除上述问题。
